Features

Why VUGVA

GPU memory is fragmented across cards. VUGVA virtualizes it into a unified pool with zero CPU overhead.

CPU-Bypass DMA

64-byte descriptor ring. CPU writes metadata, DMA engine moves megabytes. CPU never touches tensor data — only 0.003% of total transfer.

Three-Tier Hierarchy

VRAM (1,008 GB/s) → DRAM (28-58 GB/s) → SSD (5-7 GB/s). Automatic promotion/demotion based on access patterns.

Predictive Prefetch

Look-Ahead Attention Tracking predicts which layers to prefetch K steps ahead. Hides PCIe latency completely.

NUMA-Aware Routing

Bandwidth factors: 0.95 (local), 0.80 (cross-socket), 0.65 (far). Physical distance-aware data placement.

Zero Dependencies

Pure stdlib Rust. No CUDA toolkit headers needed. dlopen(3) loads libcuda.so at runtime. Works from P100 to Blackwell.

Page State Machine

5 states: Unmapped → Allocated → Resident ↔ Warm ↔ Cold. Invalid transitions rejected at runtime. Paper Figure 5.

Architecture

How It Works

Framework never touches GPU memory. VUGVA routes everything through the CPU-bypass control plane.

Control Plane (CPU)

8-byte page lookup + 64-byte DMA descriptor = 72 bytes total. The CPU only touches metadata, never data.

Data Plane (DMA)

1024-slot descriptor ring. GPU MMU handles transfers autonomously. Megabytes move while CPU does nothing.

Three Tiers

Hot → Warm → Cold. Background sweeper demotes idle pages, promotes hot DRAM pages. Framework never sees tiers.

Research

Paper Reference

"VUGVA: A Software-Defined Virtual Unified GPU VRAM Architecture with CPU-Bypass Hybrid Memory for Non-NVLink Multi-GPU Clusters"

Algorithm 1 · §3.1

Memory Interception Hook

Fast-path: if allocation fits in one GPU → native cuMemAlloc. Otherwise → shard across all GPUs via VMT.

Algorithm 2 · §5.1

Hybrid Memory Access

CPU checks page table (8B), writes DMA descriptor (64B). DMA engine transfers megabytes. Total CPU touch: 72 bytes.

Algorithm 3 · §5.2

Look-Ahead Prefetch

Predicts next K layers via attention patterns. Prefetches via P2P/DRAM DMA while GPU computes current layer.

Figure 5 · §4.1

Page State Machine

Unmapped → Allocated → Resident ↔ Warm ↔ Cold. Background sweeper promotes hot pages, demotes idle ones.

Table 3 · §4

Three-Tier Hierarchy

VRAM (<100ns, 1008 GB/s) → DRAM (2-8µs, 28-58 GB/s) → SSD (50-100µs, 5-7 GB/s). 100x bandwidth gaps.

§4.2

NUMA Router

Physical distance between Tensor Cores and tensor segments. BW factor: 0.95/0.80/0.65 based on NUMA distance.
