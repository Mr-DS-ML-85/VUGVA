API Reference

Complete public API for VUGVA v0.1.0. All functions are on VugvaEngine unless noted.
DOI: 10.5281/zenodo.21549808

Core — VugvaEngine

VugvaEngine::new

pub fn new(gpu_ordinals: &[u32]) -> Result<Self>

Initialize the VUGVA engine with one or more GPU ordinals. Discovers GPU topology, sets up P2P paths, initializes VMT and DMA ring.

let mut engine = VugvaEngine::new(&[0])?;        // single GPU
let mut engine = VugvaEngine::new(&[0, 1, 2])?;  // multi-GPU
ParameterTypeDescription
gpu_ordinals&[u32]GPU ordinals to use (from nvidia-smi)

Returns: Result<VugvaEngine> — engine ready for allocation.

VugvaEngine::allocate

pub fn allocate(&mut self, name: &str, shape: &[usize], elem_size: usize) -> Result<String>

Allocate a named tensor. Algorithm 1 from the paper. If it fits in one GPU → fast path. Otherwise → shard across all GPUs.

let name = engine.allocate(
    "model.embed.weight",  // unique name
    &[8192, 8192],        // shape
    2,                      // element size (f16 = 2 bytes)
)?;
ParameterTypeDescription
name&strUnique identifier for this tensor
shape&[usize]Tensor dimensions
elem_sizeusizeBytes per element (f16=2, f32=4, f64=8)

Returns: Result<String> — the assigned name (may differ for sharded allocations).

VugvaEngine::access

pub fn access(&mut self, name: &str, ordinal: u32) -> Result<*mut c_void>

Get the device pointer for a tensor on the specified GPU. Promotes the page to Resident state if needed. Handles NUMA-aware routing.

let ptr = engine.access("model.embed.weight", 0)?;
ParameterTypeDescription
name&strTensor name from allocate()
ordinalu32GPU ordinal to get pointer for

Returns: Result<*mut c_void> — raw CUDA device pointer.

VugvaEngine::free

pub fn free(&mut self, name: &str) -> Result<()>

Free a named tensor. Releases all shards across GPUs. Transitions pages to Unmapped state.

engine.free("model.embed.weight")?;

VugvaEngine::free_vram

pub fn free_vram(&self, ordinal: u32) -> Result<u64>

Query free VRAM on a specific GPU in bytes.

let free = engine.free_vram(0)?;  // bytes on GPU 0

Page State Machine

Vmt::demote

pub fn demote(&mut self, name: &str) -> Result<()>

Demote a page from Resident → Warm or Warm → Cold. Used by background sweeper.

Vmt::promote

pub fn promote(&mut self, name: &str) -> Result<()>

Promote a page from Cold → Warm or Warm → Resident. Triggered by access() or prefetch.

Vmt::is_valid_transition

pub fn is_valid_transition(from: PageState, to: PageState) -> bool

Check if a state transition is valid per Paper Figure 5. 8 valid, 6 invalid.

DMA Ring

DmaRing::submit

pub fn submit(&mut self, descriptor: DmaDescriptor) -> Result<()>

Submit a 64-byte DMA descriptor to the ring. CPU writes this, DMA engine picks it up autonomously.

FFI Loader

ffi::cuda_module

pub fn cuda_module() -> Result<&'static DlLib>

Load libcuda.so via dlopen. Returns cached handle on subsequent calls. All CUDA symbols are accessed through this.

ffi::nvrtc_module

pub fn nvrtc_module() -> Result<&'static DlLib>

Load libnvrtc.so via dlopen. For runtime kernel compilation. Optional — only needed if using NVRTC kernels.

sym_to_fn

pub unsafe fn sym_to_fn<F: Copy>(lib: &DlLib, name: &str) -> Result<F>

Resolve a symbol from a loaded library to a typed function pointer.

unsafe {
    let cuInit: cuInit_t = sym_to_fn(lib, "cuInit")?;
    cuInit(0);
}
