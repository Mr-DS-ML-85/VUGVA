Getting Started

VUGVA is a software-defined GPU memory virtualization library. Zero external crates, pure Rust FFI via dlopen(3). Works on any NVIDIA GPU from Tesla P100 to Blackwell.
DOI: 10.5281/zenodo.21549808

Prerequisites

  • Rust 1.70+ (stable)
  • NVIDIA GPU with compute capability sm_60 or higher
  • libcuda.so — the CUDA driver library (installed with NVIDIA driver)
  • libnvrtc.so — NVRTC library (for runtime kernel compilation, optional)
VUGVA does NOT require the CUDA toolkit headers or nvcc. It loads CUDA symbols at runtime via dlopen.

Installation

Add to your Cargo.toml:

[dependencies]
vugva = { path = "../vugva" }

Or clone and build directly:

git clone https://github.com/Mr-DS-ML-85/VUGVA.git
cd VUGVA/vugva
cargo build

Verify Installation

cargo run --example demo

This runs the full demo on your GPU — discovery, allocation, access, free, page state machine.

Basic Usage

use vugva::allocator::VugvaEngine;

fn main() -> vugva::Result<()> {
    // Initialize with GPU ordinal(s)
    let mut engine = VugvaEngine::new(&[0])?;

    // Allocate a named tensor (Algorithm 1 from paper)
    let name = engine.allocate(
        "model.embed.weight",  // unique name
        &[8192, 8192],        // shape
        2,                      // element size (bytes, f16)
    )?;

    // Get device pointer for GPU 0
    let ptr = engine.access(&name, 0)?;

    // Free when done
    engine.free(&name)?;

    Ok(())
}

Multi-GPU Sharding

When an allocation exceeds single GPU capacity, VUGVA automatically shards across all GPUs:

// 2 GPUs → 2GB tensor split into 1GB per GPU
let mut engine = VugvaEngine::new(&[0, 1])?;
let name = engine.allocate("big_tensor", &[1024, 1024, 512], 4)?;

Running Tests

# Unit tests (no GPU required)
cargo test --lib

# Hardware integration tests (requires GPU)
cargo test --test hardware

# All 42 tests
cargo test
Hardware tests check for GPU availability and skip gracefully if no GPU is found.

Compatibility

Tested Hardware

  • RTX 4060 (sm_89, 8GB VRAM) — primary development GPU
  • All architectures sm_60 to sm_120 should work
  • Single and multi-GPU configurations
